## Question and epistemic boundary

Phase E asks separately whether exact original chart structure supports non-contiguous recurrence and whether it supports stable contiguous boundary proposals. A boundary is research-derived, not an observed fact or section truth. Recurrence is not segmentation; improved reconstruction is not behavioral authority. BPM changes and isolated outliers are not boundaries by definition. Synthetic validity is not human style evidence.

No result in this phase may alter `legacy-experimental.1`, generation, RNG, F2, D1, C2, MapperSupport, quantization, defaults, CLI or Web behavior. F2 remains `CONTINUE_CONDITIONALLY`, blocked by F2.ACQ.

## Frozen corpus

The historical corpus is frozen before results through the existing `C11CorpusDiscovery`: 11 unique human charts in 11 families, keymodes 4K/7K/10K. `[ADD …]` outputs and byte duplicates are excluded. Samples and test fixtures are synthetic controls, never human evidence. No newly discovered chart may enter silently.

## Representation and feature taxonomy

`original-temporal-event-series.1` is built only from canonically ordered `OriginalObjects` through `MapperEvidenceProfile` and `BeatTimeline`. Each exact event moment preserves chart fingerprint, stable event ID, serialized time, file-derived decimal beat, exact previous spacing, simultaneous Tap/LN heads, LN releases, strictly held-before lanes and original observation IDs.

- Observed/file-derived facts: serialized timestamps, lanes, object types, timing points and simultaneous original membership.
- Exact derived from file: decimal beat coordinate, serialized spacing, release groups and held-before state.
- Research-derived: structural token, exact recurrence, change run, boundary candidate, region and held-out validation state.

The beat coordinate is not latent snap intent. There is no rounding-to-grid, epsilon, tolerance, denominator inference or F2 hypothesis domain.

## Held-out tasks and leakage

The target is the exact categorical structural token. Each task reports eligible, comparable, reconstructed, ambiguous, mismatch and no-context separately. Exact-neighbor donors match the target's exact previous/next token context, but the target event group is removed before donor construction; any donor triple touching excluded observations is rejected. Global and fixed-window references also remove the target group. Small-block holdout is used for segmentation perturbation. Provenance retains exclusions and donors. A deliberately leaky positive control must produce leakage greater than zero; correct paths must produce zero.

This task is deliberately narrow: using the target token as the value to score is valid, while donor selection cannot use that value. No combined Phase E score exists.

## Synthetic truth and negative controls

The frozen suite covers stationary, abrupt A→B, A/B/A, alternating recurrence, gradual change, isolated outlier, BPM-only change, structure-only change, short chart, LN-heavy, stable rice, sparse→dense, distant motif and multiple stable regimes. It also exercises deliberately every-event, no-boundary and BPM-boundary outputs so the evaluators can register false positives/negatives. Fixtures span 1K/4K/7K/10K/18K.

Exact synthetic boundary identity is the anchored original event ID/time/beat; no tolerance is used. Synthetic truth can validate recovery, false splits/merges, abstention, stability and leakage, but cannot establish mapper-intended human sections.

## Predefined comparisons and outcomes

No aggregate score or hyperparameter search is allowed. On humans, exact-neighbor recurrence may be considered stronger than a simple baseline only if it is not inferior in reconstructed eligible targets, improves on multiple charts/families, does not systematically increase mismatch, preserves no-context/abstention, is deterministic and is not dependent on one keymode. Stable-run segmentation is judged separately by existence across multiple charts/families, exact rerun stability, measured target/block-holdout changes and non-extreme predeclared min-run sensitivity. Human boundary accuracy is undefined because labels do not exist.

Component outcomes are frozen as authorized: A useful/stable; B partial/restricted or sensitive; C not useful/defensible. Global Outcome A requires at least one adaptive representation to pass synthetic, beat a simple baseline on sufficient multi-family human evidence, retain provenance/determinism/abstention and avoid incompatible sensitivity. Outcome B records real but restricted structure or a dependency preventing promotion. Outcome C means no defensible advantage or failed stability/sensitivity. Even Outcome A authorizes no behavior or default.
